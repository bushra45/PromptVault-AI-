# PromptVault AI

A responsive prompt library built with HTML, CSS, and vanilla JavaScript.

## Features
- Create, edit, search, and organize AI prompts
- 12 sample prompts to get started
- Categories and custom categories
- Favorites
- Sort by recently updated, recently added, title, or copy count
- Copy prompts to clipboard
- Track copies during the current session
- Save prompts and categories in browser LocalStorage
- Export and import a JSON backup
- Light and dark themes
- Responsive layout for desktop, tablet, and mobile

## Run the website
1. Extract the ZIP file.
2. Open the `PromptVault_AI` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Start creating and organizing prompts.

## Data and privacy
Prompts are stored in the current browser using LocalStorage. They are not uploaded to a server. Clearing browser site data may remove the saved library, so use **Export backup** to keep a copy.

## Project files
- `index.html` — page structure
- `style.css` — layout, colors, responsive styles, and dark mode
- `script.js` — prompt management, search, categories, favorites, import/export, and local storage
